# Security policy

AirScreen pairs a PC with a TV using a one-time pair key shown on the TV, an ephemeral P-256 key exchange, a 4-digit
number compared on both screens, and explicit approval on the TV. Media is AES-256-GCM encrypted under a per-connection key.

**Report a vulnerability privately** through GitHub Security Advisories (Security tab, "Report a vulnerability").
Please do not open a public issue for security problems. Known open items are listed in `docs/SECURITY_NOTES.md`.
